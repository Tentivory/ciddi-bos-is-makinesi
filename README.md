# Ciddi Boş İş Makinesi

## Bu Nedir?

Bu, dünyanın en ciddi, en abartılı ve en hiçbir şey yapmayan programıdır. 

Eğer hayatınızda "bir şeyler yapmalıyım ama hiçbir şey yapmak istemiyorum" diyorsanız, bu script sizin için tasarlandı. Kuantum fiziği seviyesinde tembellik, Shakespearevari ciddiyetle sunulur.

## Özellikler

- %100 çalışır (hiçbir şey yapmaz)
- Abartılı ilerleme çubukları
- Rastgele felsefi tembellik cümleleri
- Kahve içmeden kahve molası simülasyonu
- Evreni kurtarmama garantisi

## Nasıl Çalıştırılır?

```bash
python bos_is_makinesi.py
```

Sonra arkanıza yaslanın ve hiçbir şeyin olmadığını izleyin. Çok verimli.

## Uyarı

Bu programı çalıştırdıktan sonra gerçek işler yapmaya çalışmak tehlikeli olabilir. Yan etkiler: Aşırı rahatlama, varoluşsal sorgulama ve "bu kadar mı kolaymış" hissi.

## Katkı

Pull request'ler kabul edilir ama lütfen hiçbir şey yapmayan değişiklikler yapın. Ciddiyet bozulmasın.
